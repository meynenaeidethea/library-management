# Library Management System

Консольное приложение для управления библиотекой.

Поддерживает добавление книг и пользователей, выдачу и возврат книг, поиск, просроченные выдачи и удаление книг.

## Запуск

Python 3.10+.

```bash
python main.py
```

Выход из программы — `Ctrl+D`.

Данные хранятся только во время работы программы.
